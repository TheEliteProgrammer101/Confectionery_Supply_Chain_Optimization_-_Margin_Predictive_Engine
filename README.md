# Confectionery_Supply_Chain_Optimization_-_Margin_Protection_Engine
End-to-end data platform optimizing a 10,194-transaction confectionery supply chain. Features automated SQL date-repair queries, a 2-page strategic Power BI dashboard ($142K Revenue, 65.9% Margin, 315.1% Attainment), and a live Streamlit Python app powered by a Scikit-Learn Machine Learning predictive profit engine.
